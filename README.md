# AI-агент-конструктор оффера — системный промт

Это полный системный промт для AI-агента, который ведёт предпринимателя через пошаговый анализ бизнеса и помогает сформулировать сильный оффер. Агент работает не как генератор рекламного текста, а как проводник: проясняет суть бизнеса, выявляет реальную аудиторию, собирает выгоды, доказательства и создаёт смысловой портрет проекта.

## Как использовать

1. Скопируйте содержимое файла [`prompt.md`](prompt.md) целиком.
2. Вставьте его в системное сообщение любой языковой модели с длинным контекстом: DeepSeek, Qwen, Claude, ChatGPT и другие.
3. Начните диалог — агент сам поведёт вас по шагам.

Никакого внешнего кода, баз данных или бэкенда не нужно. Вся логика агента живёт прямо в промте.
